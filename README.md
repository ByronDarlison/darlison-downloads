# Darlison.com downloads

Prompts, templates, and reference files supporting the articles and tools published at [darlison.com](https://www.darlison.com/tools/).

These materials help founders define what they want from their business, understand how work moves through the company, set a clear direction, and establish accountability. Each file can be downloaded and used independently. The related article on Darlison.com provides the context behind the process.

## How to use a prompt

1. Open the Markdown file.
2. Copy the complete prompt.
3. Paste it into an artificial intelligence assistant that can hold a structured conversation.
4. Answer one question at a time.
5. Save the finished output in the system your team uses to run the business.
6. Review important decisions with your leadership team, coach, or professional advisor.

The prompts may ask for sensitive business information. Read the privacy terms of the artificial intelligence service you choose before providing confidential material.
